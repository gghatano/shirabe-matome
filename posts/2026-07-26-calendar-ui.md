## なぜカレンダーか

日付を持つコンテンツの一覧は、リストだけだと「いつの分がどれだけあるか」が見えない。カレンダーを置くと、記録の濃淡がひと目で分かる。空白の日も情報になる。

カレンダーライブラリは入れなかった。必要なのは月グリッドの描画とクリックだけで、日付演算も `Date` で足りる。

## グリッドの組み立て

`grid-template-columns: repeat(7, 1fr)` に、先頭の空セルを月初の曜日ぶん詰めるだけ。

```js
const first = new Date(y, m - 1, 1);
const startDow = first.getDay();          // 0=日
const daysInMonth = new Date(y, m, 0).getDate();  // 翌月0日 = 当月末日

let cells = "";
for (let i = 0; i < startDow; i++) cells += `<div class="cal-cell"></div>`;
for (let d = 1; d <= daysInMonth; d++) {
  const iso = `${y}-${String(m).padStart(2, "0")}-${String(d).padStart(2, "0")}`;
  // ...
}
```

`new Date(y, m, 0)` が当月の末日になるのは、月を 1 進めた上で「0 日」を指定すると前月末日に丸められるため。うるう年も月の大小も自前で判定しなくていい。

## 件数バッジと「押せる日」

全部の日をクリック可能にすると、押しても何も起きない日が大量にできて操作感が悪い。**記録がある日だけ** を押せるようにする。

```js
const n = dayCount.get(iso) || 0;
const clickable = n > 0 ? `data-date="${iso}"` : "";
```

見た目でも区別する。記録がある日は背景色を敷き、右上に件数バッジを出す。CSS の `cursor` も `pointer` と `default` で分ける。押せるかどうかが見た目とカーソルの両方で分かる状態にしておく。

## 初期表示月の決定

今月を出すのが基本だが、今月に 1 件も無いと空のカレンダーが出てしまう。そこで「今月に記録が無ければ、今日から最も近い記録日の月」にフォールバックさせる。

```js
const hasThisMonth = [...dayCount.keys()].some(iso => iso.startsWith(curPrefix));
if (!hasThisMonth && dayCount.size) {
  // 今日との差が最小の日付を探してその月を表示
}
```

過去のアーカイブを久しぶりに開いたときに、いきなり中身が見えるかどうかが変わる。

## フィルタ同士の衝突を整理する

カレンダーの日付選択と、別に置いた期間フィルタ（過去7日など）は意味が競合する。両方を同時に効かせると「7日以内かつ特定の1日」という誰も望まない結果になる。

**あとから操作したほうが勝つ** ようにした。日付を選んだら期間フィルタを解除し、期間フィルタを使ったら日付選択を解除する。排他にしておけば説明も要らない。

一方でタグ絞り込みとは自然に AND で組み合わさるので、こちらは併用させる。競合するのは「同じ軸を別の粒度で切っている」フィルタ同士だけ、と整理すると判断しやすい。

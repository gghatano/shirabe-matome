# inbox — 外部で調べたことの投入口

Claude Code や Discord を通らなかった調べものを、ここに置くと素材に混ざる。

- ChatGPT など他のツールでのやりとり（要約でも全文でも）
- 読んだ記事の URL とメモ
- 手書きのメモ

## 置き方

ファイル名の先頭に日付を付けると、その日の素材になる。

```
inbox/2026-07-28-chatgpt-http2-priority.md
```

日付を付けなければファイルの更新時刻で判定する。拡張子は問わない（テキストであればよい）。

## 注意

ここに置いた内容は **要約段（LLM）にそのまま渡る**。他のツールの出力は検証されていない
ことが多いので、要約段には「inbox 由来は未検証として扱う」よう指示してある。断定して
書いてほしいことは、自分で確かめてからメモに残すこと。

このディレクトリの中身は README.md を除いて gitignore されている。公開されるのは
posts/ に移したものだけ。
